# 15. Glossary

| Term | Meaning |
|------|---------|
| **A2 / Anstoss 2** | The game the data is converted to (Ascaron's football manager game). |
| **FM** | Football Manager, the game the data comes from. |
| **Avereine** | The 130 non-league clubs of Anstoss 2 (from 30 European nations). They are not in a playable league but appear in European competitions. |
| **CA / Current Ability** | FM's rating of how good a player is now. The converter turns it into Anstoss 2 strength 1-7. |
| **PA / Potential Ability** | FM's rating of how good a player can become. |
| **Growth room** | PA minus CA. |
| **Reputation** | FM's measure of how big a club is. Decides who moves between divisions and who gets big stadiums. |
| **Export** | Reading the data out of the FM save into CSV files inside the project. |
| **Plan** | The converter's proposal of which club plays where and who is in each squad. Editable before writing. |
| **Slot** | A fixed place in an Anstoss 2 file: a team position in a league, or a place in the last-season results (champion, UEFA Cup place 1 ...). |
| **Spare teams** | Clubs of a country file that play in no league. |
| **Pool** | The FM clubs (or players) that are not used in the plan. |
| **Project** | A named folder with the export, options, edits, written files and crests of one conversion. |
| **Written files / output** | The finished `.sav` files and crests in the project's `Anstoss2` folder. |
| **Data set / profile** | A complete copy of the game's `DATA.DEF` and `DATA.VER`. You can switch between them; one is **live**. |
| **Live** | The data set the game currently reads. |
| **Original** | The data set holding the untouched data of the installation, stored on the first install. Your way back. |
| **Partial install** | An install that only replaces some files (name pools, non-league clubs, one country) and keeps the rest. |
| **Patch file** | A single `.exe` containing a data set, created with **Generate patch file...**. |
| **Patcher** | The window a patch file opens: it installs the patch and switches data sets. |
| **Quiet mode** | Running a patch with `-q`: installs without any window, for installers. |
| **Sonstige** | German for "others": the Anstoss 2 nation used for FM nations the game does not have. |
| **Regionalliga** | The German third tier, four groups of 18 clubs in Anstoss 2. |
| **WAPPEN** | The game's crest folder (`VW_*.BMP` files). |
| **Library** | The per-user collection of club information, kits and crests that new projects start with. |
