# 16. About

## What this is

The Anstoss 2 Data Converter is an unofficial community tool that converts Football Manager save data into Anstoss 2 data files. It
works completely offline: it reads your save and your Anstoss 2 folder and writes files on your own PC. It sends nothing to anyone.

## Back up your game

Installing creates a data set **Original** with the data your installation had, so you can always return. Even so, copy your
Anstoss 2 folder (or at least your saved games) before the first install if they matter to you.
